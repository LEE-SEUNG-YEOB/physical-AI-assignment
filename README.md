# 모두길 소개·홍보 웹사이트

교통약자의 실외 이동부터 공공시설 내부 목적지까지 연결하는 도시형 Physical AI 서비스 **모두길**을 소개하는 과제용 웹사이트입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 검증 명령

```bash
npm run typecheck
npm run lint
npm run build
```

## 구현 범위

- React, TypeScript, Vite, React Router 기반 정적 웹사이트
- 서비스 소개, 주요 기능, 이용 과정, 핵심 기술, 차별점, 기대 효과의 6개 상세 페이지
- 주변 위험 감지, 접근 가능한 경로, 횡단과 공공시설 연계 소개
- 사람 감지 후 감속·안전거리 확보·정지·우회 과정 시각화
- 모바일, 태블릿, PC 반응형 레이아웃과 키보드 접근성
- 자체 제작 SVG 선형 그래픽과 Lucide 아이콘 사용

백엔드, 로그인, 회원가입, 데이터베이스와 실제 센서 연동은 포함하지 않습니다.

## 페이지 경로

- `/`: 서비스 소개
- `/features`: 주요 기능과 안전 행동 과정
- `/journey`: 서비스 이용 과정과 활용 시나리오
- `/technology`: 핵심 기술
- `/difference`: 유사 서비스와 모두길의 차별점, 단계적 구현 전략
- `/impact`: 기대 효과

운영 서버에 배포할 때는 각 경로의 새로고침 요청을 `index.html`로 연결하는 SPA fallback 설정이 필요합니다.
