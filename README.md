# 모두길 자율주행 스마트휠체어 소개 웹사이트

사전 조사된 보행 공간에서 목적지까지 이동하도록 돕는 Physical AI 기반 자율주행 스마트휠체어 서비스 아이디어 **모두길**을 소개하는 정적 웹사이트입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 검증 명령

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

## 소개 범위

- `/`: 스마트휠체어의 대상, 이동 문제와 서비스 구조
- `/features`: 장애물 인식, 통과 판단, 접근성 경로, 외부 정보 우회, 사용자 개입의 F1~F5
- `/journey`: 공원 입구에서 복지관의 접근 가능한 입구까지 약 700m 생활권 이동을 가정한 서비스 동작 예시
- `/technology`: 적용 후보 부품, 소프트웨어, 지도 데이터, 외부 공사·CCTV 정보와 유선 충전
- `/difference`: 일반 전동휠체어·자율 이동 사례와의 차이 및 제안 운영 모델
- `/impact`: 이용자, 보호자·활동보조인과 시설 운영자에게 기대하는 변화

운행 범위는 사전 지도와 노면·통과 조건이 확인된 보도, 공원 산책로, 보행자 전용도로와 공공시설 접근로입니다. 일반 차도, 자율 횡단, 계단, 지하철 승강장, 지도 없는 공간과 시설 내부 자동 이동은 현재 서비스 범위에 포함하지 않습니다.

## 구현 범위

- React, TypeScript, Vite, React Router 기반 정적 프런트엔드
- 타입이 지정된 콘텐츠 데이터와 자체 제작 SVG
- 모바일·태블릿·PC 반응형 레이아웃
- 키보드 메뉴, 단계 선택, 기술 상세 펼침과 모션 축소 대응

실제 지도 API, CCTV 영상, ROS 2, 데이터베이스, 센서, 충전소 예약이나 휠체어 제어 서버는 구현하지 않습니다. 화면의 경로와 단계 데이터는 서비스 원리를 설명하기 위한 고정 예시이며 실제 운행 기록이나 실시간 위치가 아닙니다.
